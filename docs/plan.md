> 리서치 근거: [best-practices.md](./best-practices.md) · 데이터 모델: [erd.html](./erd.html)

## 설계 원칙 (리서치에서 도출)
1. **클릭이 핵심 신호.** 오픈은 MPP로 오염 → Score·성공지표는 클릭 중심.
2. **도달률은 참여로 좌우.** 도메인 인증 + 워밍업 + 리스트 위생을 발송 전에 준비.
3. **LLM은 보조.** 요약·분류·후보추림까지, 최종 편성은 사람.
4. **빠른 파일럿.** 4주차 소규모 실발송으로 실데이터를 조기 확보해 Score 가중치 확정.
5. **세그먼트 단위.** 3,000명 전원이 아니라 program·활동도 세그먼트로 발송.

## 리스크 (스케일·인프라)
1. **발송 아키텍처** — 3,000명엔 동기 루프 불가 → 배치/백그라운드 필수(4주).
2. **도달률 워밍업** — 신규 도메인 콜드메일 위험 → 도메인 인증 조기(2주) + 활동 회원 우선 발송.
3. **프로그램 세그먼트** — 명단이 여러 과정에 흩어짐 → `program` 필드로 관리.
4. **수신 동의(법적)** — 한국은 마케팅 메일 사전 동의(옵트인) 필수. 기존 회원 동의 여부 확인 필요.
