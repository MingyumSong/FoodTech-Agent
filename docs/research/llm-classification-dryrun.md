### flash-lite 탈락 근거 (최저가지만 결함)

"해당없음" 사용: haiku 14 / flash 7 / gpt-5-mini 6 / **flash-lite 2**.
실례: 동물실험 규제 기사·의료용 오가노이드 바이오프린팅 기사를 flash-lite만 "식품프린팅"으로
분류. 분류의 주용도가 **뉴스레터 큐레이션의 노이즈 걸러내기**이므로 이 결함은 치명적.

### 불일치 양상 (17/80건, 21%)

- 대부분 인접 카테고리 경합: 스마트제조↔스마트유통(물류로봇), 스마트제조↔간편식(라면공장 투자).

## 구현 시 참고 (통합 티켓에서)

- 프롬프트·카테고리 상수는 `scripts/llm_dryrun.py`의 것을 출발점으로 (파싱 실패 0 확인됨).
- OpenRouter `usage: {include: true}`로 호출당 실비용이 응답에 담김 — 비용 로깅에 사용.
- gpt-5-mini류 reasoning 모델은 분류 태스크에 부적합(지연) — 향후 후보에서 제외.
- 발송 직전 실시간 분류 금지 — 수집 크론에서 분류까지 마치고 캐시에 저장할 것
  (분류 실패가 발송을 막지 않도록 헬스체크와 분리).
