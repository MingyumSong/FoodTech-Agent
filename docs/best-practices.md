# 뉴스레터 발송·추적·스코어링 베스트 프랙티스 (리서치 요약)

> 2026-07-08 딥리서치 결과. 24개 소스 → 117개 주장 → 25개를 3표 교차검증(25/25 confirmed).
> 우리 맥락: 푸드테크 커뮤니티 ~3,000명, 주 1회 뉴스레터, FastAPI + PostgreSQL + Resend.

---

## 1. 추적 — 오픈은 버리고 클릭 중심으로

- **MPP(Apple Mail Privacy Protection)** 가 픽셀을 사람보다 먼저 자동 로딩 → 가짜 오픈 발생. 도입 6개월 만에 측정 오픈율 **+18%p(40%↑)** 부풀려짐. 애플 메일이 전체 클라이언트 **~46%**.
- **MPP는 클릭 추적에는 영향 없음.** Gmail·Yahoo·Outlook은 **참여(클릭)를 받은편지함 배치 알고리즘에 직접 반영**.
- **적용:** Activity Score 주 신호 = **클릭**. 오픈은 약한 보조. `/r/{token}` 클릭 리다이렉트가 핵심. Resend 웹훅(delivered/clicked/bounced/complained) → `events` 적재.
- 출처: Litmus, Mailchimp, HubSpot.

## 2. 크롤링·발송 — 일 수집 / 주간 발송 + 도메인 인증 선행

- 소스: **RSS/Alerts + API**, API 본문 잘리면 전문 추출로 보완. **일 수집 / 주간 요약·발송 2단 스케줄**.
- **SPF**(도메인당 1개 정책, 서브도메인 미상속) · **DKIM**(제공자별 서명) · **DMARC**(none→quarantine→reject 단계 상향). Resend 지원.
- **워밍업:** 단계당 ≤1.5배 증량, **최근 참여자(14~30일)부터**. 우리는 3,000/주라 Resend 7일 기준(150→2,000/일)이 최대치를 넘어 **워밍업 ~1주**면 충분. 단 첫날 몰빵 금지.
- 출처: Resend(공식), Customer.io(공식), Mailgun.

## 3. 스코어·세그먼트 — 비활동 = "클릭 없음"(오픈 아님)

- **dormant 정의 = 롤링 기간 내 클릭 없음.** sunset policy(비활동 정리) + win-back(재참여) 후 suppress.
- 리스트 위생 ↔ 도달률 직결: **위생점수 95%↑ → 받은편지함 97%** vs 85%↓ → 76%.
- **적용:** active 세그먼트 = "베네핏 줄 회원". 비활동 정리가 전체 도달률을 지킴.
- 출처: Mailchimp, Customer.io, Klaviyo, Mailgun.

## 4. 대시보드 — 오픈율 대신 클릭·CTOR·구독취소

- 벤치마크: Mailchimp 오픈 35.6%/클릭 2.62%/구독취소 0.22%, HubSpot CTOR 5.3%. **오픈 수치는 MPP 인플레이션이라 목표로 쓰지 말 것.**
- **추적 지표:** 클릭율, CTOR(오픈 대비 클릭), 구독취소율, 리스트 성장률, 내부 클릭 기반 Activity Score.
- 출처: Mailchimp, HubSpot, Brevo.

## 5. LLM — 요약·분류·후보추림은 시키되, 최종 편성은 사람

- 파이프라인(RSS→추출→구조화 프롬프트→저장)은 싸고 빠름(~$0.15~1/회, ~12분). 구체 분류 정확(F1 0.94).
- **뉴스 가치 판단은 사람과 26.7%만 일치** → **human-in-the-loop 필수.** LLM은 요약·분류·후보 추림까지, 최종 선별·프레이밍은 편집자.
- 요약은 시맨틱 청킹 + ~10% 오버랩, 관심사 필터로 노이즈 80% 감소 가능.
- 출처: arXiv 2509.25491, 실무 파이프라인 사례들.

## 우리가 정해야 할 열린 질문 (리서치가 답 안 준 부분)

| # | 정할 것 | 힌트 | 확정 시점 |
|---|---|---|---|
| A | Activity Score 가중치 (클릭/오픈/베네핏/회신) | 클릭 ≫ 오픈, 공식은 없음 | 초안 1주 → 실데이터로 5주 |
| B | active/dormant 임계 (주간 발송 기준 몇 주 무클릭) | 일반 6~12개월, 고빈도엔 부적합 | 초안 1주 → 5주 조정 |
| C | Resend 웹훅 → events 매핑 | 소스 없음, Resend 문서로 확정 | 3주 구현 |
| D | 우리 벤치마크 목표 (에디토리얼 클릭율) | 마케팅 평균만 있음 | 5~6주 |

### Activity Score 스트로맨 (출발점)
```
클릭       = 3점   ← 주 신호 (MPP 안 탐)
베네핏참여  = 5점   ← 오프라인 행사참석/혜택사용 (가장 강한 의도)
회신/전달   = 4점   ← 강하지만 포착 어려움 (후순위)
오픈       = 1점   ← 약한 보조 (MPP 노이즈)
구독취소    = 제외/음수
+ 최근일수록 가중(시간 감쇠), 롤링 12주 윈도우
```

## 주의(caveats)
- 벤치마크·워밍업 수치는 벤더별이고 주기적으로 바뀜 — 하드코딩 전 재확인.
- 공개 오픈율(35~42%)은 MPP로 부풀려진 값 → 우리 오픈율 판단 기준으로 쓰지 말 것.
- LLM 큐레이션 근거는 단일 arXiv 프리프린트(narrow) → 방향성 참고용.
