# T-010: 파이프라인 현황판 (싱크 데모용, 읽기 전용)

Status: DONE (2026-07-22 — 구현·테스트 3개·운영 데이터 스크린샷 검수 완료. 배포는 railway up 시 반영)

## Problem

시스템이 6단계 파이프라인으로 돌아가고 있는데 확인 수단이 터미널 쿼리뿐이다.
싱크에서 교수님·희정님께 보여줄 운영 현황 화면이 필요하다.

## Scope (읽기 전용 — 조작 버튼 없음)

- `GET /admin/status` — HTTP Basic 잠금(비밀번호 = ADMIN_TOKEN, 매직링크 전 임시).
- 단계별 카드: ① 회원(총원·구독·프로그램별) ③ 수집·분류(오늘 적재·누적·카테고리 분포·최근 수집 시각)
  ④ 발송(최근 뉴스레터·발송 수) ⑤ 추적(이벤트 유형별 집계·최근 이벤트) ⑥ Score(미구현 표시).
- 푸디픽 파란 팔레트, 서버 렌더 단일 HTML. PII(이메일·이름) 표시 금지 — 집계 숫자만.
- 조작 버튼·쓰기 기능은 명시적으로 범위 밖 (매직링크 티켓에서).

## Acceptance Criteria

- [x] AC1: Basic 인증 없이 401, ADMIN_TOKEN으로 접속 시 현황 렌더.
- [x] AC2: 회원·뉴스·발송·추적 카드에 실데이터 숫자 표시, PII 없음.
- [x] AC3: 스크린샷(데스크톱) 검수 기록. check.sh 통과.

## Verification

로컬 렌더 + 스크린샷 → 배포 → 운영 URL에서 실데이터 확인.
