# T-024 메인/에피타이저를 '심도'로 가른다 + 칼럼·연재 걸러내기

Type: FEAT
Status: DONE (2026-08-09)

## Problem

- **현재 동작:** 어떤 기사가 메인이고 어떤 게 에피타이저인지를 **중요도로 정하지 않는다.**
  `select_picks`는 해외 꼭지를 메인에 먼저 넣고, 남는 메인 자리를 국내로 채운 뒤
  **나머지를 자동으로 에피타이저**로 돌린다(`pilot_daily.py:151-153`).
  심도·중요도라는 개념이 코드에 아예 없다.
- **기대 동작:** 에피타이저 = 푸드테크를 얕게 스치는 소식, 메인 = 심도 있고 중요한 사건.
  (파일럿 수신자 피드백의 정의를 그대로 옮긴다.)
- **왜 필요한가:** 실제로 그 결과가 매일 나가고 있다.
  - #018(2026-08-09) 메인 1번 = `[경제인칼럼] 동네상권 위기의 외식업` — 칼럼이 그날의 얼굴이 됐다.
    `top_title = mains[0]`이라 **메일 제목까지 그 칼럼**이었다.
  - 같은 편에 `[기획연재]FTA 20년, K-농업의 '신 물류'` — 연재 해설.
  - #016(08-07) 제목 = `[더벨][thebell interview | 건설부동산` — 식품 기사가 아닌 것이 메인에 앉았다.

  즉 지금 메인 자리는 "중요한 것"이 아니라 "국내 목록의 앞 두 개"다.

## Acceptance Criteria

1. 게이트 응답에 `depth`("main" | "light")가 포함되고, 통과 항목에 실려 나온다.
2. 심도 판정이 있으면 **메인 자리에 `depth="main"`이 우선 배치**된다.
3. 심도 판정이 없거나 게이트가 실패하면 **기존 순서 그대로** 나온다(회귀 없음).

5. LLM 호출 횟수는 그대로(조립당 게이트 1회, 실패 시 재시도 1회).

## 구현하며 드러난 것 (2026-08-09)

### ① 게이트가 재현되지 않고 있었다 — 이게 근본 원인이었다

`_call_openrouter`가 `temperature`를 안 넘겨 모델 기본값으로 돌고 있었다.
**같은 풀(112건)을 두 번 돌린 결과가 drop 31건 vs 13건.** 두 번째 실행에선 프롬프트가
명시로 금지한 것들(`[더벨] 건설부동산 AX 기업`, `LG CNS 밸류 재평가`, `국산 NPU 600억`)이
통과했다. #016에 건설부동산 기사가 실린 것도 이 경로로 설명된다.

→ `temperature=0` 고정. 두 번 돌려 MAIN 목록이 **바이트 단위로 동일**함을 확인했다.
   프롬프트를 고쳤을 때 고쳐졌는지 알 수 있게 된 것이 이 변경의 실제 값어치다.
   (분류 프롬프트도 같은 함수를 쓰므로 함께 결정적이 된다 — 개선이지만 인지하고 있을 것.)

### ② 이진 판정은 변별을 못 했다 → 1~5 등급

첫 설계는 `depth: "main"|"light"`였는데 실측에서 **main이 66/95 = 70%**로 나왔다.
국내 4꼭지 중 3개가 "main"이면 메인 2자리는 결국 목록 순서로 정해진다.
→ 1~5 정수로 바꾸고 "4~5는 전체의 20% 이내"를 명시. 최종 실측: **4=17 / 3=37 / 2=5**,
   메인 후보는 EU PPWR 포장규제·배양육 싱가포르 출시·CJ슈완스 신공장,
   최하위는 aT 간담회 4건. 의도대로 갈렸다.

### ③ 심도 정렬이 '기사 회전'을 깼다 — 스코프를 넓혀 함께 고침

예전엔 `_take_rotated`가 분야별 **최신** 1건을 골라서 새 기사가 들어오면 어제 것이 자연히
밀려났다. 심도 우선 정렬은 그 회전을 깬다 — 심도 4짜리는 7일 창이 끝날 때까지 자기 분야
맨 앞을 지킨다. 드라이런에서 **D+1과 D+2의 메인 3꼭지가 완전히 같게** 나왔다.

→ `_drop_already_sent` 추가. 지난 편이 실은 URL을 `target_filter.item_urls`(기존 JSONB,
   T-023의 `member_ids`와 같은 자리)에 남기고 다음 조립에서 뺀다. 스키마 변경 없음.
   **풀이 얇아지면 배제를 포기한다** — 중복 노출은 거슬리는 정도지만 조립 실패는 그날
   발송이 통째로 없어지는 일이다.
