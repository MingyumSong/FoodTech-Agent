왜 FOODIE 표기

진짜 영어 단어라 즉시 읽히고 FOODIE's PICK이 문법적으로도 자연스러움. 단어 자체가 흔해 변별력이 낮으므로, 대외 노출은 항상 "푸디픽" 조합으로, "푸디" 단독은 화자 이름으로만.

페르소나 운용 원칙

  • 말투는 존댓말 "합니다"체 고정, 이모지는 제목 1개·본문 0개까지만 — 임원 독자 기준

  • 답장하면 운영진이 실제로 읽는다고 푸터에 명시 — 답장 자체가 참여 신호

실제 이메일 구현 시 제약

  • 본문 폭 600px · 테이블 레이아웃 · 인라인 CSS — 이 시안의 시각 언어를 그 제약 안에서 재구현
  • 이미지 최소화: Gmail은 102KB 초과 시 본문을 잘라내고, 이미지 차단 시 레이아웃이 무너짐 → 텍스트 우선
  • 다크모드: 메일 클라이언트의 색 강제 반전 대비, 순백/순흑 대신 톤 있는 색 사용
  • 수신거부 링크(unsubscribe_token)는 정보통신망법 필수 요소 — 푸터 고정
